Wähle deinen Stil

Jeder Stil hat eigene Bilder, Geräusche und Musik. Das Spiel ist überall gleich, und du kannst den Stil jederzeit wechseln, sogar mitten im Spiel.

Zum Spielen brauchst du eine echte Tastatur. Auf einem Tablet geht auch eine Bluetooth-Tastatur.

Type Defender ist kostenlos, ohne Werbung und ohne Anmeldung. Alles bleibt auf diesem Gerät. Quellcode und Lizenz auf GitHub
